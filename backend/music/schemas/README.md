The SEPA credit transfer exporter validates pain.001.001.09 against the unmodified
GBIC 5 technical validation subset published by Deutsche Kreditwirtschaft:

https://www.ebics.de/de/datenformate/ergaenzende-dokumente

Source archive: `DK-TVS_SEPA_GBIC_5zzglISO_Originale.zip`, schema dated 2025-04-01.
The XML uses the production ISO namespace, EUR and individual booking requests.
Schema validation cannot establish bank acceptance, execution or payee ownership.
Users must check the file and approve it separately at their bank.
