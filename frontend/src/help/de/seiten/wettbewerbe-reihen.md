Eine Reihe fasst einen Wettbewerb zusammen, der regelmäßig wiederkehrt, zum Beispiel das jährliche Pokalschießen. So bleibt die Geschichte über die Jahre sichtbar.

Auf der Webseite steht das Archiv einer Reihe unter einer lesbaren Adresse aus ihrem Namen, etwa `/ergebnisse/reihe/pokalschiessen/`. Ihr könnt sie bei der Reihe unter **Adresse auf der Webseite** ändern; frühere Adressen leiten weiter.
