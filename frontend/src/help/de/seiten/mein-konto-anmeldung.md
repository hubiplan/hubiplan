Hier änderst du dein Passwort und schaltest die **Zwei-Faktor-Anmeldung** ein oder aus. Mit ihr
braucht man zum Anmelden außer dem Passwort einen Code vom Handy. Wer Rollen verwaltet, Exporte
macht, in der Kasse bucht, alle Mitglieder sehen darf oder Protokoll und Postausgang liest, muss sie
einrichten; für die Plattform-Verwaltung gilt das sofort. Vor heiklen Aktionen wie einem
vollständigen Export fragt HUBIplan erneut nach einem Code (Anleitung „Zwei-Faktor-Anmeldung
einrichten“).

Eine neue Adresse unter **Anmelde-E-Mail ändern** gilt erst, wenn du sie mit dem Link an die neue Adresse bestätigt
hast. Hast du kein eigenes Passwort und meldest dich nur über Links an, musst du den Wechsel
zusätzlich mit dem Link an deine bisherige Adresse bestätigen. Nach dem Wechsel sind deine anderen
Browser abgemeldet; die App bleibt verbunden.
