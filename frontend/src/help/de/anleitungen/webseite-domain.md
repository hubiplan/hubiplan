1. Öffne [Domain](/webseite/domain).
2. Trage die Adresse ein, etwa „www.musterverein.example“, und klicke auf **Domain hinzufügen**.
3. Lass bei eurem Domain-Anbieter die Domain auf den Server eurer HUBIplan-Instanz zeigen; die Angaben dafür nennt, wer die Instanz betreibt.
4. Prüfe im Browser, ob die Webseite unter der neuen Adresse erscheint.
5. Klicke bei der gewünschten Adresse auf **Als Hauptadresse**.

Der Betreiber muss die Domain auch auf dem Server einrichten, samt Zertifikat; sprich die Umstellung vorher mit ihm ab.
