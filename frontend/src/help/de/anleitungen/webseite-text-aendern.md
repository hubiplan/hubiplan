1. Öffne die [Inhalte der Webseite](/webseite/inhalte).
2. Wähle den Text, den du ändern willst.
3. Schreibe die Änderung; HUBIplan speichert, sobald du tippst.
4. Lege mit **Bildunterschriften auf der Webseite zeigen** fest, ob unter den Bildern eine Unterschrift steht.
5. Prüfe das Ergebnis auf der Webseite.

Die letzten Fassungen jedes Texts bleiben erhalten.
