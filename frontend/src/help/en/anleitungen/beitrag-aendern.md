Before you start: the body responsible under the constitution, usually the general meeting, has decided the new fee.

1. Open [Finance › Set up › Fee rates](/finanzen/einrichtung/beitraege).
2. Change the amount under **Annual fee per membership type**. You adjust age brackets and reductions below.
3. Calculate the next fee run with **Calculate preview** and compare the total with the previous year.
4. Announce the new fee to the members, for example with a [circular](/hilfe/rundschreiben-verschicken).

Invoices already issued do not change. The new rates apply to every fee run you calculate afterwards. So only change them once the last run at the old fee is finished.
