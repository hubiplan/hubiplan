1. Open the member's file in the [member list](/mitglieder).
2. Under **More actions** choose **Record leaving**, enter the day of death as the **Leaving date** and choose death as the reason.
3. Click **Save leaving**. Offices, membership type and sub-units end on the same day.
4. Check on the **Fees** tab whether invoices are open or a fee was overpaid, and clarify this with the relatives.
5. If the person paid for a household, set a new payer there, see [Create a household](/hilfe/haushalt-anlegen).

The file stays with the former members so that membership periods and honours are kept for the club's history. Circulars and invoices no longer go to the person afterwards.
