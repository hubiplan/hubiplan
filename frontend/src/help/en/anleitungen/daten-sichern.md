1. Open [Settings › Data transfer](/einstellungen/datenuebernahme).
2. Under **Full export** choose the unit and the scope. With **with files (logos, receipts, photos, constitution) as ZIP**, receipts and photos come along too.
3. Start the export and download the file as soon as it is ready. HUBIplan deletes it after 7 days.
4. Keep the file encrypted and separate from the computer. It contains all personal data.

The export is your own copy, for example for a move to another instance. Independently of that, the operator backs up the server; ask there how often. User accounts and passwords are not included in the export.
