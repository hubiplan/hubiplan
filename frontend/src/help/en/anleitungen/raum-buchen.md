1. Open [Bookings](/belegung) under Equipment & rooms.
2. Choose **Book**.
3. Choose the item, purpose and time, or instead of a time an event that the booking then follows.
4. Set a weekly, monthly or yearly repetition if needed.
5. Tick **Only the managers see the purpose** if others should only see “booked”.
6. Save the booking; if the item needs approval, it is a request at first.
7. For lent equipment, the administration confirms **Confirm hand-out** and later **Confirm return**.

If the item is already booked, HUBIplan names the booked time. You cancel single dates of a series with **Cancel this date only**.
