This shows the web address where the website can be reached and how to set up your own domain.

Images for AI assistants: under “Allowed servers” you enter host names from which a connected AI assistant may fetch images by address, such as `cloud.example.org` for the club’s Nextcloud. HUBIplan downloads the image itself, only via https and only JPG, PNG or WebP, and checks it like any upload. If the field stays empty, images only arrive via an upload link that the assistant offers in the chat.
