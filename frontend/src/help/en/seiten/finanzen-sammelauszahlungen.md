In **Batch payouts** (Finance, Book), select approved outstanding remuneration, a bank account and an execution date. Check each holder, IBAN and optional BIC. Saving a run for review reserves claims and freezes amounts and recipient details. Download the SEPA file (pain.001.001.09, EUR), check it and approve it at your bank. Repeated downloads contain the same instruction; do not submit the file twice.

Export does not execute transfers or mark claims paid. The file requests individual bank entries. Assign each actual expense in the performance settlement; bank account and amount must match. Reversed bookings reopen reconciliation. Cancelling a run releases claims; submitted transfers must also be stopped at the bank. Finance read access permits inspection; edit access is required to prepare, export or cancel.
