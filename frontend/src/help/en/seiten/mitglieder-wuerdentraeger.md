This lists the holders of your club's titles, such as kings and princes, year by year. This forms the chronicle, which can also appear on the website.

Name searches ignore letter case and normalize Unicode spelling variants; “ß” and “ss” are treated as equal. Other selected filters still apply.

Ordinals (“Hans II.”) count per first name, ignoring upper and lower case; hyphen and space count the same (“Hans-Peter” = “Hans Peter”, but not “Hans”). Set exceptions as a manual ordinal. When you link a name entered as text to a member, HUBIplan asks whether further entries with the same name should be linked too; otherwise the same person counts twice. The list is sorted by year or start date.
